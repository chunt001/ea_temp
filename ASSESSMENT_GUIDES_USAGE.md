# Assessment Guides - Usage Guide

## 🎯 Purpose

The **Assessment Guides** page provides real-time reference material during business-technology assessment workshops and discussions. It displays the scoring criteria and guidance for all three assessment dimensions.

## 📊 What's Included

### **Business Health Assessment Guide**
Assesses capabilities **independent of technology**:

**Dimension 1: Strategic Importance**
- Mission-Critical (5)
- Important (4)
- Supporting (3)

**Dimension 2: Operational Health**
- Healthy (5)
- Moderate Concerns (3)
- Unhealthy (2)

### **Business-Technology Fit Assessment Guide**
Assesses how well technology serves the capability:

**Dimension 1: Automation Level**
- Highly Automated (5)
- Partially Automated (3)
- Mostly Manual (2)
- Fully Manual (1)

**Dimension 2: Technology Fit**
- Excellent Fit (5)
- Adequate Fit (3)
- Poor Fit (1)

### **Technology Health Assessment Guide**
Assesses technical health from IT perspective:

**Dimension 1: Technology Operational Health**
- Healthy (3)
- Moderate Concerns (2)
- Unhealthy (1)

**Dimension 2: Technology Direction Alignment**
- BCI Technical Standards
- Cloud Strategy
- Zero-Trust Security
- AI Enablement

## 🔄 How to Use During Workshops

### **Pre-Workshop:**
1. Open guides.html on a second screen or tablet
2. Review the criteria before the session
3. Bookmark for quick access

### **During Workshop:**
1. **Toggle between guides** using the top navigation buttons
2. **Share screen** showing the relevant guide
3. **Read criteria** to stakeholders as you ask questions
4. **Reference specific guidance** when there's confusion

### **Workshop Flow Example:**

```
You: "Let's assess Contract Negotiation capability"

[Switch to Business Health Guide]

You: "First, how critical is this capability to BCI's mission?"
     [Show Strategic Importance scale]
     
Stakeholder: "It's essential for every deal"

You: "That sounds Mission-Critical. Let me read the criteria..."
     [Read: 'Essential to BCI's investment mandate..']
     
Stakeholder: "Yes, that's us - Mission-Critical"

[Mark down: Strategic Importance = 5]

You: "Now for operational health - any pain points?"
     [Switch to Operational Health scale]
     
Stakeholder: "We have delays and workarounds"

You: "That sounds like Moderate Concerns..."
     [Read criteria]

[Mark down: Operational Health = 3]
```

### **Best Practices:**

✅ **Use "All Guides" view for printing** - Give to participants
✅ **Toggle during discussion** - Show only relevant dimension
✅ **Read criteria verbatim** - Ensure consistent scoring
✅ **Pause for questions** - Let stakeholders discuss
✅ **Refer back often** - Keep calibration consistent

## 🖨️ Printing Guides

### **Quick Print:**
Click the print button (🖨️) in bottom-right corner

### **Print All Guides:**
1. Click "All Guides" button
2. Click print button or Ctrl/Cmd + P
3. Each guide starts on new page
4. Give to workshop participants

### **Print Single Guide:**
1. Select the guide you want
2. Click "Print This Guide" button
3. Only that guide will print

## 💡 Tips for Effective Use

### **Calibration:**
At the start of your assessment:
1. Show all guides to the team
2. Walk through 1-2 example capabilities
3. Ensure everyone understands the scales
4. Reference guides throughout to stay consistent

### **When Stakeholders Disagree:**
1. Show the relevant criteria on screen
2. Read the "Select if:" guidance
3. Discuss which description best fits
4. Use examples from their experience

### **Complex Assessments:**
For capabilities that are hard to score:
1. Score each dimension separately
2. Use the guidance for edge cases
3. Document rationale in notes
4. Come back to disputed ones at the end

## 🔗 Integration with Dashboard

The guides use the **same scoring methodology** as the dashboard:

```
Assessment Guide → Scores → Excel File → Convert to JSON → Dashboard
```

This ensures **complete alignment** between:
- How you assess capabilities (using guides)
- How you record them (in Excel)
- How they're visualized (in dashboard)
