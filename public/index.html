📋 Required Excel File Structure

Your Excel file must contain these sheets:

  • Business Capability Catalog - L1 and L2 capabilities with descriptions
  • BH Assessment - Business Health scores (Strategic Importance, Operational Health)
  • BTF Assessment - Business-Technology Fit (Automation Level, Technology Fit)
  • Bus-Tech Map - Mapping of capabilities to technologies
  • Technology Catalog NEW - List of technologies with priorities (optional)

The system will validate your file structure and show any errors before processing.
